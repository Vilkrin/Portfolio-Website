# Andrew Beechey --- Portfolio Website

Personal portfolio website for
[andrewbeechey.me.uk](https://andrewbeechey.me.uk), showcasing my work
across web development, Laravel applications, IT support, and
infrastructure.

## About

I'm an IT and web developer based in London, UK. This website brings
together selected projects, experience, technical skills, education, and
contact information.

Projects featured include:

- **LaraCMS** --- a content management system built with Laravel.
- **LumenGallery** --- an image gallery application built with
  Laravel.
- **Vilkrin** --- my personal website under my gaming handle.

## Technology

- **Laravel** --- application framework
- **PHP** --- application language
- **Tailwind CSS 4** --- styling, managed through the Laravel Vite
  build pipeline
- **Vite** --- frontend asset development and production builds
- **Livewire** --- reactive components
- **Flux UI** --- interface components
- **Google Fonts** --- Public Sans, JetBrains Mono, and Bricolage
  Grotesque

The site's visual design uses a dark navy palette with amber accents and
a code-editor-inspired aesthetic. Portfolio-specific colours and
typography are defined in `resources/css/app.css` using Tailwind CSS 4
theme variables.

## Website Sections

- **Home** --- introduction, overview, and featured projects
- **Projects** --- project details
- **Experience** --- professional and practical experience
- **Skills** --- technical skills
- **Education** --- education and training
- **Contact** --- contact information

## Notes
